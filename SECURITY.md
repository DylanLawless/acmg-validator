# Security

This software is a local research/development toolkit. It is not a regulated EHR interface and has not been validated for patient care. Use only synthetic or institution-approved data during development. The browser tool does not upload files or make external API requests; the CLI reads only files specified by the user.

Do not submit sensitive case data in public issues. To report a security issue privately, contact admin@switzerlandomics.ch. Before deploying with clinical data, assess local disk encryption, authorised access, retention, logging, electronic signatures and governance requirements. Do not run the local server on publicly reachable interfaces.
