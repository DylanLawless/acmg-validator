ACMG Validator

To assess a genetic variant reliably, we need to know what evidence was checked, what was found and where the information came from. A blank field does not tell us whether evidence was absent, the result was uncertain or the check was never done. ACMG Validator checks structured JSON or TSV files, keeping verified evidence, confirmed problems and missing information clearly separate. This makes assessments easier to review, share and analyse without losing their original meaning.

Import JSON or TSV, inspect consistency checks and export portable records or an experimental QEM matrix. Standardised data can support laboratory and EHR integrations through documented mappings, although this toolkit does not provide direct EHR connectivity. Processing is local, without an account or data upload.

1. Prepare and import

Use the TSV template or a JSON record. Each TSV row represents one ACMG criterion for one variant, so the template has 28 rows per variant. Keep the same item_id for each variant's criteria, use a new ID for each additional variant, and edit the source file before reimporting any corrections.

3. Export

Export canonical JSON for a complete structured record, TSV for spreadsheet-based review, an HTML audit or a QEM bundle for downstream analysis. A valid QEM export can still contain NA outcomes; it does not establish that every applicable check was completed or that a clinical conclusion is correct.

QEM and QuantBayes

The SGA-QEM standard defines the negative-rule convention. The QuantBayes R package analyses evidence sufficiency using the binary QEM matrix, with additional macOS and Linux tools. Its score depends on the declared rules and their denominator; it is not a measure of clinical validity or proof that all applicable reviews are complete.

QEM rules ask whether qualifying evidence is invalidated or weakened. TRUE → 0 means a confirmed invalidation; FALSE → 1 requires a check showing no invalidation and verified qualifying evidence; NA → 0 means the evaluation is inconclusive or missing. Enter the answer in qem_raw_outcome; keep qem_source_ref and qem_verified distinct from ACMG evidence fields.

Scope

This independent open-source toolkit validates and converts existing reviews. For manual entry and assessment of an individual variant, the Switzerland Omics ACMG Validator is available separately. Neither tool substitutes for a qualified clinical interpretation.
